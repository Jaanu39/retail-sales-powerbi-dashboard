# Retail Sales Power BI Dashboard

## Project Overview

Interactive retail sales dashboard developed using Power BI to analyze sales performance, customer behavior, product performance, and regional performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Dashboard Features

- Sales and profit analysis
- Sales trend analysis
- Customer behavior analysis
- Product performance analysis
- Regional performance analysis
- KPI cards
- Interactive slicers and filters
- Star-schema data modelling

## Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Quantity

## Dashboard Pages

### Page 1 – Overview
Provides an overall view of sales and business performance using KPI cards and interactive visuals.

### Page 2 – Sales Analysis
Analyzes sales trends and performance across different categories and regions.

### Page 3 – Customer Analysis
Analyzes customer behavior and purchasing patterns.

### Page 4 – Product Analysis
Analyzes product performance and identifies important sales patterns.

## Project Files

- Power BI dashboard: `powerbi/Retail Sales Dashboard.pbix`

## Project Objective

To transform retail sales data into an interactive Power BI dashboard that helps analyze business performance and identify useful sales and customer insights.
